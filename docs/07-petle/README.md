# 07 - Pętle

Pętla pozwala powtarzać te same instrukcje wiele razy.

Bez pętli trzeba byłoby ręcznie przepisywać podobne polecenia. Z pętlą program może wypisać wiele liczb, wczytać serię danych, policzyć sumę albo przejść przez znaki napisu.

Prosta analogia: pętla działa jak polecenie "powtarzaj tę czynność, dopóki warunek jest spełniony". Warunek pętli jest pytaniem zadawanym przed następnym powtórzeniem albo po wykonaniu ciała pętli, zależnie od rodzaju pętli.

## Kolejność nauki

Najpierw poznasz `while`, czyli pętlę sterowaną warunkiem. Potem zobaczysz `do-while`, która wykonuje ciało co najmniej raz. Następnie poznasz `for`, licznik, akumulator, wybór właściwej pętli, pętle zagnieżdżone, `break`, `continue` oraz pętlę zakresową dla napisu.

## Po ukończeniu rozdziału

Po tym rozdziale będziesz umieć:

- pisać pętle `while`, `do-while` i `for`,
- dobrać rodzaj pętli do problemu,
- stosować licznik i akumulator,
- unikać przypadkowych pętli nieskończonych,
- pisać proste pętle zagnieżdżone,
- świadomie używać `break` i `continue`,
- przechodzić po znakach napisu pętlą zakresową.
