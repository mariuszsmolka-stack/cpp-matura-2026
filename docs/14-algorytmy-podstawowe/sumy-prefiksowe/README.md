# Sumy prefiksowe

Jak szybko obliczać sumy różnych fragmentów tej samej tablicy? Zapisz sumy od początku tablicy. Potem wykorzystaj je w kolejnych obliczeniach.

## Kiedy tego użyć?

Gdy wiele pytań dotyczy sum spójnych fragmentów tablicy, a dane nie zmieniają się między pytaniami.

## Kiedy wybrać coś innego?

Przy jednym pytaniu zwykła pętla często wystarczy. Jeśli dane często się zmieniają, trzeba uwzględnić koszt ponownego obliczania prefiksów.

## Przed rozpoczęciem

Powtórz indeksy tablic, pętlę `for` i dodawanie kolejnych wartości do zmiennej. Te umiejętności wystarczą do pierwszej lekcji.
