# Sito Eratostenesa

Wyznaczamy liczby pierwsze do ustalonej granicy. Zamiast osobno szukać dzielników każdej liczby, wykreślamy wielokrotności.

## Kiedy tego użyć?

Gdy potrzebujesz wielu liczb pierwszych z jednego zakresu albo wielokrotnie pytasz o pierwszość liczb z tego zakresu.

## Kiedy wybrać coś innego?

Dla jednej małej liczby często wystarczy sprawdzenie dzielników. Dla bardzo dużej granicy tablica oznaczeń może wymagać zbyt dużo pamięci.

## Przed rozpoczęciem

Powtórz dzielniki, wielokrotności, zwykłe tablice, `bool`, pętle `for` i instrukcję `if`.
