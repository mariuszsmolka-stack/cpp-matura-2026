# 09 - Zakres zmiennych i funkcje

Duży program łatwiej zrozumieć, gdy dzielimy go na mniejsze części. Funkcja jest takim nazwanym fragmentem programu. Wykonuje jedno zadanie i może być wywołana wiele razy.

W tym rozdziale zobaczysz też, że zmienna nie jest dostępna automatycznie w całym programie. Miejsce, w którym zmienną można użyć, nazywamy jej zakresem.

## Czego nauczysz się w tym rozdziale

Po tym rozdziale będziesz umieć:

- rozpoznawać zakres zmiennej,
- odróżniać zmienne lokalne od globalnych,
- tworzyć proste funkcje `void`,
- przekazywać dane do funkcji przez parametry,
- zwracać wynik przez `return`,
- odróżniać przekazywanie przez wartość od przekazywania przez referencję,
- dzielić prosty program na czytelne funkcje.

## Kolejność nauki

Najpierw poznasz zakres zmiennych. Potem zobaczysz przesłanianie i zmienne globalne. Następnie przejdziesz do funkcji bez parametrów, funkcji z parametrami, wartości zwracanych oraz referencji. Na końcu połączysz wszystko w prostym programie podzielonym na funkcje.
