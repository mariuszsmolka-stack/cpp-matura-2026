# Algorytmy zachłanne

Podejmujemy kolejne decyzje według jednej reguły. Sprawdzamy, czy ta reguła daje najlepszy wynik. Zaczynamy od wyboru zajęć do jednej sali. Potem przydzielamy sale wszystkim zajęciom.

## Kiedy tego użyć?

Gdy zadanie wymaga kolejnych wyborów i potrafisz uzasadnić, że każdy wybór pozostawia możliwość uzyskania najlepszego wyniku.

## Kiedy wybrać coś innego?

Jeśli reguła zawodzi na kontrprzykładzie, trzeba szukać innej metody. Zmiana celu, np. z liczby zajęć na ich łączną wartość, może wymagać programowania dynamicznego.

## Przed rozpoczęciem

Powtórz zwykłe tablice, pętle, instrukcję `if` i porównywanie liczb. Sortowanie przez wybieranie jest objaśnione w lekcji.
