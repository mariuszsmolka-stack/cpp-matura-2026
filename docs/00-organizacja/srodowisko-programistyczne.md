# Środowisko programistyczne

Do pracy z C++ można używać różnych środowisk. Na tym etapie kurs nie narzuca jednego programu jako jedynego dozwolonego.

Możliwe środowiska:

- Code::Blocks,
- Visual Studio,
- CLion,
- kompilator internetowy.

Najważniejsze jest to, aby środowisko pozwalało tworzyć pliki `.cpp`, kompilować program i uruchamiać wynik.

Szczegółowa konfiguracja środowisk będzie omawiana tylko wtedy, gdy będzie potrzebna przy konkretnym zadaniu.
