# Kompilacja i uruchamianie

Program w C++ trzeba najpierw skompilować. Kompilator sprawdza kod i tworzy program, który można uruchomić.

## Co sprawdza kompilator?

Kompilator informuje między innymi o:

- literówkach w słowach kluczowych,
- brakujących średnikach,
- złych typach danych,
- błędach w nawiasach,
- użyciu niezadeklarowanych zmiennych.

## Jak pracować z błędami?

Nie poprawiaj wszystkiego naraz. Zacznij od pierwszego komunikatu, sprawdź wskazany wiersz i popraw jedną rzecz. Potem skompiluj program ponownie.

Po kompilacji uruchom program i sprawdź wynik na kilku zestawach danych.
