# Jak pracujemy

Na kursie pracujemy krok po kroku. Najpierw rozumiemy problem, potem zapisujemy pomysł, a dopiero później piszemy kod w C++.

## Zasady pracy

- Przepisuj przykłady samodzielnie.
- Zapisuj programy w plikach `.cpp`.
- Kompiluj program po istotnych zmianach.
- Czytaj komunikaty kompilatora.
- Testuj rozwiązania na różnych danych.
- Wykonuj ćwiczenia stopniowo.
- Wracaj do wcześniejszych działów, gdy nowe zadanie wykorzystuje znane konstrukcje.

## Przed oddaniem rozwiązania

Sprawdź, czy program się kompiluje, działa dla danych przykładowych i dla danych brzegowych. Upewnij się, że nazwy zmiennych są czytelne, a kod jest uporządkowany.
