# Organizacja kursu

## Cel kursu

Celem kursu jest przygotowanie ucznia do swobodnej pracy z językiem C++ oraz do rozwiązywania zadań algorytmicznych i maturalnych.

## Jak korzystać z kursu

Lekcje należy realizować po kolei. Przykłady warto przepisywać samodzielnie, kompilować i uruchamiać po małych zmianach. Komunikaty kompilatora traktujemy jako wskazówki, które pomagają poprawić program.
