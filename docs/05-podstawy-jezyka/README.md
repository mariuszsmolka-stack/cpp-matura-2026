# 05 - Podstawy języka C++

W tym rozdziale poznasz pierwsze elementy języka C++. Zobaczysz, z czego składa się prosty program konsolowy, jak wypisywać dane, jak tworzyć zmienne, jak wczytywać informacje od użytkownika i jak formatować podstawowe wyniki.

Przykłady wykorzystują aplikacje konsolowe w Code::Blocks. Dzięki temu od razu widzisz tekst wpisywany przez użytkownika i wynik działania programu.

## Jak uczyć się tego rozdziału

Idź po kolei. Najpierw poznaj budowę programu, potem nagłówki i komentarze, następnie wyświetlanie danych, zmienne, typy i wczytywanie danych. Dopiero później przejdź do `using namespace std;`, większych typów liczbowych, konwersji oraz `getline` i formatowania wyników.

## Po ukończeniu rozdziału

Po tym rozdziale powinieneś umieć napisać prosty program konsolowy w C++, użyć `std::cout` i `std::cin`, dobrać podstawowy typ danych, utworzyć zmienną albo stałą, wykonać proste obliczenia, świadomie użyć `using namespace std;`, rozpoznać problem konwersji typów oraz sformatować prosty wynik liczbowy.
